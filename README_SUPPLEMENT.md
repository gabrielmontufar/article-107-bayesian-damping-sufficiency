# MIIUM30-62 — paquete suplementario reproducible

Este suplemento acompaña la revisión mayor del manuscrito y conserva el código,
los datos públicos utilizados, los resultados derivados y las figuras de alta
resolución. No contiene información personal ni versiones de autoría.

## Contenido

- `code/`: `run_synthetic_validation.py`, `run_real_acceleration_pilot.py`,
  `SMC_Modal.m` y la nota de reproducción sintética.
- `data/`: fuentes públicas de aceleraciones y procedencias, incluido el
  SHA-256 del ZIP Mendeley archivado.
- `results/`: CSV, JSON y figuras generadas para la calibración sintética y el
  piloto operacional.
- `figures/`: figuras PNG a 300 dpi, 2160×1260 píxeles.
- `checksums_sha256.txt`: SHA-256 de cada archivo del suplemento.

El suplemento está publicado en el repositorio público
`https://github.com/gabrielmontufar/article-107-bayesian-damping-sufficiency`
en el commit `bd2ee08ec2495c2b2ca3145a2c488bc37d654073`. Este archivo conserva
la entrega suplementaria verificable de la revisión.
